# 通用区域方向校正

用于横置或倒置表格，不按题号、文件名或表名设置旋转。

- RegionRef 增加 rotation_degrees，默认 0，只允许顺时针 0/90/180/270 度。
- 定位器依据可见文字方向声明角度；bbox 始终是原始页面上的归一化坐标。
- Pillow 在高清区域裁剪完成后旋转；旋转角度纳入缓存键，旧缓存不会误用。
- OCR、结构专家、受限结构补丁使用同一方向校正区域，完整页面仍保留作为上下文。
- 不改变原始文档，不改变结构坐标校验，不扩大受限补丁的允许修改范围。
- 结构提示强调正向逻辑行列和父子表头的实际覆盖边界，不把同页不同表格拼宽。

局限：方向仍由定位模型判断，不能保证选对；旋转只能改善可读性，不能自动纠正
错误的列集合、跨页归属或结构范围。涉及这些问题的候选仍可能失败。

无新增依赖；使用项目已有 Pillow、Pydantic、pytest。
测试覆盖四种角度、顺时针方向、缓存隔离及原图不变。

```bash
pip install -e '.[dev]'
pytest -q
ruff check src tests
```
